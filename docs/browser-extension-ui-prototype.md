# 浏览器扩展 UI 原型文档

> 适用项目：小红书运营助手（xhs-ops-agent）  
> 版本：v1.0  
> 日期：2026-09-02

---

## 1. 设计原则

1. **最小打扰**：扩展不强制弹窗、不后台开标签，只在有任务时通过图标红点和系统通知提醒
2. **完全透明**：每个字段的填充状态必须可视化，用户清楚知道系统做了什么
3. **随时可控**：用户可以随时暂停、取消、手动补全
4. **一致性**：视觉风格与 Web App 保持一致（主色 #FF2442，圆角 16px，浅色背景 #F5F5F5）

---

## 2. 扩展图标状态

扩展图标固定在浏览器工具栏，根据状态变化：

| 状态 | 图标 | 说明 |
|------|------|------|
| 默认 | 灰色 Logo | 无任务或未登录 |
| 有任务 | 红色 Logo + 数字角标 | 显示待处理任务数量 |
| 填充中 | 红色 Logo + loading 动画 | 正在执行自动填充 |
| 错误 | Logo + 红色叹号角标 | 轮询失败或填充严重错误 |

| 状态 | 图标 | 文案 | 操作 |

| pending | ⏳ | 等待填充 | 无 |
| filling | 🔄 | 填充中... | 取消 |
| success | ✅ | 已填充 | 复制 / 查看 |
| failed | ❌ | 填充失败 + 原因 | 复制原文 / 重试 |
| skipped | ⏭️ | 已跳过 | 恢复 |

## 10. 交互流程图

### 10.1 主流程

```
Web App 生成结果页
    │
    ▼
点击「发布到小红书」
    │
    ▼

    │
    ▼

    │
    ▼
扩展 Service Worker 轮询到任务
    │
    ▼
图标红点 + 系统通知
    │
    ▼
用户点击 popup / 通知
    │
    ▼
打开 creator.xiaohongshu.com/publish
    │
    ▼
检测登录态
    │
    ├── 未登录 ──▶ 提示登录 ──▶ 轮询检测 ──▶ 继续
    │
    ▼
自动填充内容
    │
    ▼
侧边栏显示字段状态
    │
    ▼
用户检查并手动发布
    │
    ▼
扩展上报 published
```

## 11. 响应式考虑

扩展 popup 在高分屏/缩放场景下需保证：
- 最小宽度 320px 可读
- 文字不溢出卡片
- 图片缩略图固定 60x60px
- 操作按钮在窄宽度下垂直堆叠
