# 小红书运营助手 - 完整交互原型

## 文件说明

- `index.html`：完整交互原型（单文件，包含所有 P0/P1/P2 功能演示）

## 使用方式

直接用浏览器打开 `index.html`：

```bash
open /Users/yeluo/Desktop/xhs-ops-agent/prototype/index.html
```

或把文件拖到浏览器中打开。

## 原型包含的功能（对应 PRD）

### P0 功能
- **生成笔记**：主题/受众/类型/语气输入，生成完整图文方案
- **结果展示**：标题、正文、标签、封面文案、封面设计建议、图片脚本、合规检测、发布建议
- **历史记录**：本地保存、搜索、筛选、删除
- **合规检测**：独立文本检测页面
- **账户与订阅**：免费版/基础会员/高级会员展示

### P1 功能
- **对标笔记分析**：输入链接或正文，分析并仿写
- **模板库**：按品类分类的爆款模板，支持一键应用
- **浏览器插件**：插件状态、一键导入功能

### P2 功能
- **批量生成**：一次输入多个主题，批量输出笔记
- **真正一键自动发布**：账号授权、风险提示、发布队列
- **合规评分**：综合评分 + 多维度合规指标
- **数据复盘**：生成/发布趋势、爆款类型表现、核心数据指标
- **AI 生成封面**：Mock 的 AI 封面生成功能
